# Web UI

This directory contains the user interface for controlling the OmniBot.

## Files
*   `ui.html`: A standalone HTML/JS dashboard control panel.

## Usage
1.  Connect your device to the same Wi-Fi network as the OmniBot (or the OmniBot's Hotspot).
2.  Open `ui.html` in a modern web browser (Chrome, Firefox, Edge).
3.  Enter the IP address displayed on the OmniBot's OLED screen into the UI connection field.
4.  Use the on-screen joystick or buttons to control the robot.

## Features
*   **Virtual Joystick**: For omnidirectional manual control.
*   **Status Indicators**: Shows connection health.
