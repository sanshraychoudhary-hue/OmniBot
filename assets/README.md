# Project Assets

This folder contains media and visual assets for the OmniBot project.

## Contents
*   **Images**: Photos of the robot (`1.jpeg`), diagrams (`block diagram.png`, `softwareFlowchart.png`), and generated visualizations.
*   **Videos**: Demonstration videos of the robot in action (`Bot1.mp4`, `Bot2.mp4`, `OmniServe.mp4`).
*   **Graphics**: Logos and presentation materials.
