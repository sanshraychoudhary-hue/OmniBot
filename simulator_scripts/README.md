# Simulator Scripts

Python scripts for simulating the kinematics and behavior of the OmniBot.

## Files
*   `omni_bot_simulator.py`: Main simulation script.
*   `omni_sim.py`: Kinematics module used to calculate wheel ticks and trajectories.

## Requirements
*   Python 3.x
*   NumPy (`pip install numpy`)
*   Matplotlib (likely required for plotting in `omni_bot_simulator.py`)

## Usage
Run the simulator to visualize path planning and kinematic equations before deploying to the real robot.
```bash
python omni_bot_simulator.py
```
